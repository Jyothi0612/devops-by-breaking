# Author solve-through

Automated verification is complete only for the commits linked in `PROGRESS.md`.
It does not establish that the author solved a lab independently.

The development branch contains seventeen new v0.2/v0.3 labs for this review. For each lab:

1. Close its solution and hints. Run `./dbb start <id>` and read the ticket.
2. Solve it using the workspace and your own debugging steps; run `./dbb check`.
3. Record your time and the evidence that led you to the repair.
4. Review the AI-drafted “Say it in an interview” answer, adapt it as needed, and
   explain it without reading. The draft does not establish personal experience.
5. After solving, inspect each shortcut and explain aloud why the check rejects it.
6. Run `./dbb stop` before starting the next lab.
